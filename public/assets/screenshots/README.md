# BTTUNE Screenshots Folder (`assets/screenshots/`)

Yahan aap apne Android phone se BTTUNE app ke real screenshots add kar sakte hain.

### Recommended File Names:
1. `hero-screen.png` - Hero section ke phone mockup ke andar ka main screen (e.g. Now Playing screen).
2. `screen-1.png` - Home & Explore / Discovery Screen.
3. `screen-2.png` - 8D Spatial DSP Studio & Equalizer Screen.
4. `screen-3.png` - Syllable-Level Karaoke Lyrics Screen.
5. `screen-4.png` - Offline Music Downloads & Library Screen.
6. `screen-5.png` - Homescreen Widget / Lockscreen Controls.
7. `screen-6.png` - Pure AMOLED Dark Themes Canvas.

Jab aap in filenames ke sath images yahan daal denge, to website automatically inko display karegi!
